Security Matrix

3-Tier Role-Based Access Control

Strict row-level multi-tenancy isolating subscriber data from unauthorized parties.

1. Subscription Customer (Portal) Can ONLY read own contracts and invoices where partner_id == user.partner_id. Strictly restricted from dashboard and financial analytics.
2. Subscription Officer (Staff) Operational processing of orders, quotations, manual recurring invoices, and payment confirmations. Restricted from system configuration.
3. Subscription Administrator (Manager) Unrestricted governance: plan creation, variant surcharge rules, automated cron scheduling, and executive financial reports.
