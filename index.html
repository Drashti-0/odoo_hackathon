Brightloop Subscriptions

An enterprise recurring billing & contract automation module built by Team AuraMinds

View GitHub Repository

Core Features

Automated Recurring Billing

Cron-driven invoice generation aligned with weekly, monthly, and annual subscription cycles.

Contract Lifecycle Management

Real-time tracking of active, pending, paused, and expired client agreements.

Detailed Billing Logs

End-to-end transparent auditing for every transaction, quotation, and invoice trigger.

Native Odoo Integration

Direct hook into standard Invoicing and Quotations views without breaking core models.

Module Architecture & Views

  • menu_views.xml: Custom top-level menu and hierarchical sub-menus for Brightloop Subscriptions.
  • billing_log_views.xml: Dedicated tree and form views for tracking invoice execution pipelines.
  • subscription_views.xml: Interactive form views displaying pricing terms, renewal dates, and status badges.
  • invoice_views.xml: Customized accounting invoice links for real-time reconciliation.

Technical Stack & Configuration

Framework: Odoo 17/18 Community | Language: Python 3.x, XML | Database: PostgreSQL
