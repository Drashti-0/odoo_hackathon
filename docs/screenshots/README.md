# Screenshot Evidence

This directory is reserved for real screenshots captured from the running local Odoo application.

The authenticated admin dashboard was opened and a real screenshot was displayed in the task conversation. The browser page screenshot export saved only the Odoo form toolbar rather than the dashboard. The pre-existing tracked `admin-dashboard.png` also contains only the toolbar, so it is retained but is not suitable as dashboard evidence. The task-conversation screenshot is not stored as a reusable image in this directory.

Product/plan, quotation, invoice/billing, payment/report, and authenticated customer portal screenshots were not verified/captured for this submission. Capture them only by visiting the actual pages in the running Odoo instance with authorized internal or synthetic portal accounts.
